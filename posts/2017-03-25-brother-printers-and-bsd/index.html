Brother printers and BSD

March 25, 2017 One-minute read
Technology

My Brother MFC-7820N recently gave up the ghost and I was on the market for a new one. Since I was comfortable with the Brother brand, I decided to get another Brother printer. The MFC-L2720DW caught my eye for being in the same price bracket and also offering wireless AirPrint and Google Cloud Print capabilities. This saved me the trouble of having to configure a separate print server to serve it. While configuring the printer with Apple and Windows devices was easy, configuring it to work on FreeBSD was a different ball game altogether. In the end, I had to follow these steps to get the printer working on FreeBSD :-

Install the print/cups-filter package. This was not installed by default with the print/cups package. Download /usr/local/etc/cups/mime.types from GitHub. Enter the device URI as lpd://pcl_p1 Point at the generic PCL printer driver as the device driver

Only then did the printer start working on FreeBSD. I didn’t try extracting the .deb or .rpm device driver packages that Brother had on its website though.>
