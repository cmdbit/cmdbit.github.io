Google Chromium OS

December 8, 2009 2-minute read
Technology

One of my pet projects now is researching into lightweight desktop environments. It’s not really an operating system per se, as most, if not all of these environments run on top of Linux. Desktop enviroments are just that - environments that provide the user an area to work on.Google Chromium was the first one under the microscope. Having followed the instructions from Google, I compiled the OS under Ubuntu 9.10 and subsequently dumped the image onto a 2GB thumbdrive. Booting the laptop with it was a simple matter of adjusting the BIOS to boot from USB and sticking the thumbdrive in. Switched on the laptop and off it went.To be honest, there’s a lot to like about Chromium. A simplistic user interface, fast Javascript execution and Flash compatibility means that any user can pick up a netbook and use the Web in a matter of seconds (12 seconds, actually). I can envision a whole gathering of old people using their netbooks without having to ask for guidance. That’s cool.But I’m not sure for other users. Take, for example, power users. Power users like me would want to use more than just the Web even if that netbook is a secondary PC. We would want to tinker with the innards, use 3G broadband or even watch a DIVX movie or two on the netbook. All these you can’t do at this stage of development.So I wiped off the Google Chromium OS build on my laptop. It just didn’t fit the bill for me.
