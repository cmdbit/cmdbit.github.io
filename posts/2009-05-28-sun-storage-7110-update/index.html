Sun Storage 7110 update

May 28, 2009 One-minute read
Technology • Business

Ahh … I finally managed to find the solution to that storage issue I was facing at Te Puke.The Sun Storage 7110 was running the Solaris CIFS service which enabled Windows machines to see the SMB shares. The problem was that although the system could join the domain, it could not authenticate to the DC, with the end-result that it could only see security principals on itself and not the domain.After 4 hours of gingerly poking around, I figured out that nothing was wrong with the AD controller, and focused all my attention on the storage box. It was then that I discovered that the storage box was deliberately parsing only the first 16 characters of the domain. I downloaded a system update for the Solaris box and after installation, voila, the domain security principals could be seen.I must have been the happiest man alive when I saw that … haa haa … Probably a reminder to self : remember to apply all software updates before implementation. :)
