Stupid Windows 2003 Server

April 7, 2010 One-minute read
Technology • Business

My colleague had a very interesting brush with Windows 2003 Server today.Apparently, what happened was that Citrix failed to function for a particular user on this server. He rebooted the server, and took the opportunity to install 2 updates, KB960362 and KB980182. After the reboot, the Citrix Licence Service failed to function, and a look at the services entailed the following messages :- net start slsvcThe Software Licensing service is starting.The Software Licensing service could not be started.A system error has occurred.System error 5 has occurred.access is denied. Obviously, my friend was in a bit of flurry, and emailed out to ask if anyone had similar issues after patching.Then came the shocker.I couldn’t help but laugh at the error message. :)
