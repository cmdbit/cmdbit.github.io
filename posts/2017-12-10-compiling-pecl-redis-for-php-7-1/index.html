I followed mostly John Ramsden’s post in getting Nextcloud installed on a dedicated machine running FreeBSD. His post was direct and straight to the post and contained all the information I needed to get up and running. One major difference my setup had was that I ran Nginx as the webserver and not Apache. This is mostly due to personal taste; I simply preferred Nginx as I was familiar with it. access_log off; } } One point which John had in his post was about recompiling pecl-redis for PHP 7.1. In its default configuration, pecl-redis is compiled against php56. Since the intent here was to use PHP 7.1, using the packaged version of pecl-redis wasn’t an option. It was Poudriere to the rescue again to build a custom .pkg file for pecl-redis. All I had to do was to insert in a line into /usr/local/etc/poudriere.d/-make.conf. #DEFAULT_VERSIONS+=ssl=openssl apache=2.4 php=7.1 mysql=5.7 perl=5.24 perl5=5.24 pgsql=9.6 python=2.7 python2=2.7 python3=3.4 ruby=2.3 samba=4.6 and /usr/loca/etc/ports.lst databases/pecl-redis After the 2 lines were added, the Poudriere build was run manually to ensure that the build was successful. I must not forget to lock the custom pecl-redis package either . pkg lock pecl-redis
