Tape autoloader commandline control

February 5, 2009 2-minute read
Technology • Business

I recently discovered a new toy while playing around with the tape autoloader in one of my projects.The backup software that we bought had a child application that couldn’t work on Solaris x86, which is really dumb considering the installed x86 base out there. I was left to find an alternative.I decided to script out the backup routines, using only GNU Tar and nothing else. This presented a huge problem. How was I to control the tape library using nothing else but commandline applications? The mt command does not allow control of the tape autoloader at all, and there was a web management interface for the autoloader, it’s not really desirable where doing bash scripting is involved.Enter MTX. MTX is a commandline application that allows control of the tape autoloader instead of the usual control from the application. Which means that scripting, etc, etc is made so much easier.I downloaded the necessary packages need for installation from SunFreeware.com.
